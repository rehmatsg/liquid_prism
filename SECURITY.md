# Security Policy

## Supported Versions

Security fixes are applied to the latest major release line (`1.x`).

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through GitHub Security Advisories at
<https://github.com/rehmatsg/liquid_prism/security/advisories/new>.

Include:
- Affected version and platform (iOS/Android/Flutter version)
- Reproduction steps or minimal proof of concept
- Impact assessment

You can expect an acknowledgment within 5 business days.
