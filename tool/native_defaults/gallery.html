How to read this comparison

Captured on the same iPhone 17 Pro simulator, iOS 27.0 (24A434), 402 × 874 points at 3×. Native controls use genuine XCTest touches. The gallery removes the system status bar from its viewport. Images are lossless WebP conversions of the original captures.

The page backgrounds and 2-point selected-tab blur already match native. The calibration adjusts regular frost, dark face grading, standalone shadows, button defaults and showcase separators. Gaussian frost and tone rolloff are renderer fits; their values are separate from the directly measured UIKit filter inputs.

SF Symbols and Cupertino glyph outlines, text metrics and some control geometry still differ. This gallery makes those differences visible; it does not assert pixel identity. The before revision is available for the resting matrix and eight showcase pages. Holds show a settled press, and release captures follow the same interaction sequence; these stills do not establish continuous animation parity.
